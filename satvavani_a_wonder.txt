================================================================================
           SATYAVANI AI: AN ADVANCED PRODUCTION-GRADE AI ENGINEERING SYSTEM
================================================================================

YES, this is a very advanced, production-grade AI engineering project.
It is significantly more sophisticated than a standard AI chatbot or typical tutorial app.

While a basic AI chatbot is simply a single script that forwards user prompts to an API,
Satyavani AI is a full-lifecycle Anti-Hallucination Retrieval-Augmented Generation (RAG)
engine backed by an automated real-time news crawler and a vector database.

--------------------------------------------------------------------------------
1. ARCHITECTURAL COMPARISON: BEGINNER VS. SATYAVANI AI
--------------------------------------------------------------------------------

1. AI Strategy:
   - Beginner App: Blindly trusts the LLM; hallucinates fake news when asked rumors.
   - Satyavani AI: Anti-Hallucination Guardrails. The LLM is strictly constrained.
     If reputable news outlets haven't reported a claim, it assigns "UNVERIFIED"
     or "CONTRADICTED" with cited sources and confidence scores.

2. Workflow Orchestration:
   - Beginner App: Single prompt API call.
   - Satyavani AI: Multi-Step Graph (LangGraph). Routes user queries through:
     Intent Classification -> Query Normalization -> Vector Evidence Retrieval ->
     Strict Verdict Synthesis -> Anti-Hallucination Output Validation.

3. Vector Database & Storage:
   - Beginner App: In-memory dummy list or local ChromaDB file.
   - Satyavani AI: PostgreSQL + pgvector. Uses an enterprise relational database
     with HNSW (Hierarchical Navigable Small World) indexing for ultra-fast,
     scalable cosine distance search.

4. Database Migrations:
   - Beginner App: None or unmanaged db.create_all().
   - Satyavani AI: Alembic Versioning. Structured schema migrations and database
     revision tracking for tables, foreign keys, and vector indices.

5. Multilingual Embeddings:
   - Beginner App: Basic English-only embeddings.
   - Satyavani AI: Multilingual Dense Embeddings using BAAI/bge-m3 (1024 dimensions)
     supporting cross-lingual semantic search across English, Hindi, and Telugu.

6. Data Ingestion Pipeline:
   - Beginner App: Static hardcoded text files or copy-pasted data.
   - Satyavani AI: Automated Real-Time Crawler. A background daemon (APScheduler)
     continuously fetches live RSS feeds (The Hindu, BBC, PIB, NDTV), extracts full text
     with Trafilatura/BeautifulSoup, chunks, embeds, and purges articles older than 14 days.

7. System Architecture:
   - Beginner App: Single monolithic script.
   - Satyavani AI: Decoupled Full-Stack Architecture. FastAPI backend with
     sliding-window rate limiting and async lifecycle management, paired with a
     Streamlit frontend with multilingual typography (Devanagari, Telugu, Latin).

--------------------------------------------------------------------------------
